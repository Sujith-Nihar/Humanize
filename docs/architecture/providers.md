# Provider boundary

Review uses ModelProvider only. Adapters implement OpenAI Responses, Gemini authorization-key REST/SDK, OpenRouter as an independent adapter, and native Ollama chat on the runner. Zod is canonical; project a supported JSON Schema and validate every returned result locally. Capability tests include a small schema and the application-shaped schema.

Normalize AUTH, PERMISSION, MODEL_UNAVAILABLE, UNSUPPORTED_CAPABILITY, RATE_LIMIT, TIMEOUT, TRANSPORT, REFUSAL, CONTEXT_LIMIT, INVALID_OUTPUT and CANCELLED. Keep sanitized request IDs/retry metadata and actual provider/model usage when supplied; unknown usage is not zero.

Cloud deadline 90 seconds; Ollama 180 seconds; at most two transient retries with jitter/retry headers, bounded by job deadline. At most one invalid-output repair; refusals are not repaired. Disable compounded SDK retries. Default fallback is empty. Explicit cloud chains are audited; private execution permits only approved local models. Fixed cloud endpoints only. Ollama endpoint comes from local administrator configuration, never repository content. Ollama requests set an explicit context window covering the whole budgeted request, because the server defaults to a small window and silently discards the overflow; chat truncation drops the oldest messages first, so the system prompt carrying the untrusted-content boundary would be evicted while the repository text it governs survived. A selected local model must therefore support at least that window. Reasoning is disabled for structured calls, and only for a model whose declared capabilities include it, because reasoning tokens are drawn from the same bounded output budget as the answer and a thinking model otherwise exhausts the budget before emitting any JSON. Require local-only Ollama server settings and reject cloud models.

References: [OpenAI](https://developers.openai.com/api/docs/guides/structured-outputs), [Gemini keys](https://ai.google.dev/gemini-api/docs/api-key), [Gemini schema](https://ai.google.dev/gemini-api/docs/structured-output), [OpenRouter](https://openrouter.ai/docs/guides/features/structured-outputs), [Ollama](https://docs.ollama.com/capabilities/structured-outputs). Live probes are release evidence; mocks alone never establish compatibility.
