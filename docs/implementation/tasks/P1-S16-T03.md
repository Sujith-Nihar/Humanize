- Evidence: Encrypted provider credential administration implemented as write-only ingress. POST /api/credentials accepts a secret, stores it through an injected CredentialAdmin port and returns only an identifier and provider name; a test saves sk-SENTINEL-VALUE and asserts the response body does not contain it, and that the listing endpoint returns metadata only, so a saved secret is never readable through any endpoint (ADR-035). Revocation is proven to reach the store with the correct tenant and identifier. The encrypted store behind the port already exists and is separately proven against PostgreSQL to hold ciphertext only, to separate tenants, and to refuse a revoked credential. Results: pnpm check 199 unit tests across 33 files.
