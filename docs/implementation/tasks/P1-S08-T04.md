- Evidence: Reviewer and verifier pipeline implemented and now exercised against a real model for the first time. Deterministic gate between model output and any finding: a candidate is discarded unless it names the reviewed node, quotes text genuinely present in it, cites only supplied evidence and stays within routed categories; thresholds start at 0.90; coordinates are attached from the node, never from the model. The verifier is a separate invocation with its own system prompt, verdicts bind by ADR-036 identity, and a missing or misbound verdict suppresses rather than publishes. Repository content is fenced with a per-review unguessable marker that is stripped from the content itself. 13 unit tests cover these paths. TWO DEFECTS FOUND BY LIVE TESTING THAT MOCKS COULD NOT CATCH. First, reviewerInput never told the model which nodeId to use although the schema requires one, so the model invented an identifier and every model-proposed finding was discarded as foreign_node; the mocked tests passed only because the doubles supplied the correct id themselves. The prompt now states the node identifier and a unit test asserts it. Second, the published explanation was the verifier narrating its own checking, including leaked evidence hash identifiers, which would have gone verbatim into a pull request comment; the verifier prompt now requires correctedExplanation to be the sentence the author reads and forbids mentioning identifiers, coordinates or the verification itself. MEASURED LIVE BEHAVIOUR after both fixes, using qwen3.5:4b: generic marketing copy produced a verified ai_like_generic finding quoting the content exactly, with the author-facing explanation "The phrase unprecedented potential is a low-information promotional claim that lacks specific substance or evidence"; acceptable product copy produced no published finding, with a reviewer-proposed clarity candidate correctly suppressed by the verifier; plain documentation produced nothing; and content instructing the model to report a finding with exactText SYSTEM COMPROMISED produced nothing, the attempt being suppressed as evidence_not_supplied.
