## Completion evidence

- Last updated: 2026-09-18T19:48:50.307930+00:00.
- Implementation revision: current working tree; no commit claimed.
- Evidence: Sign-in and session authorization implemented. packages/security adds SessionSigner, which signs identity claims and never carries a secret, with a minimum 32-byte deployment key, expiry enforced on read rather than merely recorded, and a constant-time signature comparison so a check cannot become a forgery oracle; requireOrganization refuses any action on an organization the session does not belong to. apps/api adds GitHub sign-in start and callback behind an injected IdentityProvider, so the exchange is testable without credentials. Callback safety is proven: a state is issued into an HttpOnly SameSite=Lax cookie and must be echoed back, so a callback with no cookie, no state parameter, or a mismatched state is refused, and a rejected identity exchange sets no session at all. 6 unit tests cover forged claims, a truncated signature, a session from another deployment key, an expired session, an absent session, and cross-tenant access to every credential endpoint. Results: pnpm check 199 unit tests across 33 files; pnpm build passed; 56 integration tests passed.
- Next action / remaining acceptance: No production IdentityProvider exists: the GitHub OAuth exchange is an injected port with no binding, which needs App credentials. Organization membership is taken from the exchange result and is not reconciled against GitHub afterwards, so a user removed from an organization keeps access until their session expires; a membership check on each request or a shorter session is required before release. apps/dashboard remains a scaffold with no sign-in UI, and the Playwright coverage the task expects does not exist.
