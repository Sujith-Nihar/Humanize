## Completion evidence

- Last updated: 2026-09-18T17:06:42.405721+00:00.
- Implementation revision: current working tree; no commit claimed.
- Evidence: Placeholder preservation implemented in packages/suggestions/src/placeholders.ts and enforced before any suggestion is built. The placeholder multiset is compared before and after: a removed placeholder, an added one, an altered name, a changed repetition count and a reordered positional format are each rejected with a distinct reason. Ordering is checked only for positional formats such as %s and %d, which bind by position, so reordering them silently swaps the values a user is shown; named placeholders may move freely. A rewording that keeps every placeholder intact is accepted. Tests cover all five violations and the accepting case, plus an end-to-end refusal proving a suggestion that would drop a placeholder is never published. Results: pnpm check 173 unit tests across 29 files.
- Next action / remaining acceptance: ICU plural and select expressions are treated as opaque placeholders rather than parsed, so a replacement that restructures an ICU message is refused rather than validated; a dedicated ICU validator remains future work.
