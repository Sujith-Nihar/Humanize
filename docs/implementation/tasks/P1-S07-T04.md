## Completion evidence

- Last updated: 2026-09-17T20:22:30.156586+00:00.
- Implementation revision: current working tree; no commit claimed.
- Evidence: Job-scoped GitHub credential issuance implemented and its acceptance criterion proven: wrong scope or a revoked lease cannot receive a token. RunnerStore.leaseScope(credential,leaseId,fence) resolves only a live lease, applying the same liveness conditions as renewal (authenticated unrevoked runner, owning runner, exact fence, state LEASED, unexpired, repository enabled, installation neither suspended nor deleted, run not STALE/CANCELLED/COMPLETE/FAILED_FINAL) and returns only installation and repository identity plus head SHA. GitHubTokenBroker.scopedToken returns token and expiry for a single repository_ids entry with contents:read for the read role; publish permissions are unchanged and unavailable to runners. apps/api exposes POST /runner/leases/:leaseId/token behind a TokenIssuer port, so the issuer is structurally unreachable until the lease resolves. Tests: 4 unit cases in apps/api/runner.test.ts (issuer called exactly with the lease installation and repository and role read; LEASE_LOST returns 409 with the issuer never called; unauthenticated, malformed lease id and malformed fence never reach the service, and a path traversal does not resolve to the route; issuer failure returns a generic 503 that does not contain the token or key text) and 6 PostgreSQL 18.6 cases in apps/api/lease-token.integration.test.ts driving the real store over HTTP: a live lease yields a token scoped to exactly that installation and repository id, while a superseded fence, an unknown lease id, another tenant runner, an expired lease, a lease released back to the queue, a cancelled run, a disabled repository, a suspended installation and a revoked runner credential are all refused with the issuer never invoked. The T02 integration test now asserts that identity endpoints never invoke the issuer at all. Results: pnpm check passed with 46 unit tests across 12 files; pnpm build passed; 27 integration tests passed from a freshly created disposable humanize_test database.
