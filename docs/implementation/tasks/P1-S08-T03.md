## Completion evidence

- Last updated: 2026-09-18T18:16:33.527299+00:00.
- Implementation revision: current working tree; no commit claimed.
- Evidence: Deterministic rules and routing implemented and since improved by measurement. Rules emit the documented AI-style signals without any model, every span comes from the node text, and output is sorted for reproducibility; a test asserts no description ever claims machine authorship (INV-006). The router maps content kind and length to categories: a marketing paragraph receives the full set, a button label never receives long-form prose review, accessibility text receives clarity and terminology only, and disabled categories never route. TWO IMPROVEMENTS DRIVEN BY THE REVIEW GOLD SET. First, phrase matching was literal, so "leveraging the power of" did not match the listed "leverage the power of" and a passage fell below the cluster threshold, producing no finding; matching is now inflection-aware across ordinary English endings, verified by a test over leverage, leverages and leveraging. Second, the corpus showed the missed cases shared a shape the product had no rule for at all, namely wordiness and padding as distinct from promotional vocabulary; a padding rule family now covers constructions such as provides users with the ability to, it is important to note that and in order to get started, marked standalone under ADR-037 because they are countable, with a test asserting direct writing carries none. MEASURED EFFECT on the 26-case gold set: overall recall rose from 50% to 80%, clear-cut recall from 80% to 100%, ambiguous recall from 20% to 60%, and PRECISION REMAINED 100% throughout, so nothing was gained by becoming noisier. Results: pnpm check 189 unit tests across 31 files.
- Next action / remaining acceptance: Two ambiguous cases remain missed and are being left alone deliberately: ai-assisted-residual would require adding empowers, seamlessly and streamline to the phrase list, and vague-tagline is a five-word heading the router intentionally does not send for long-form review. Both fixes would fit the corpus rather than generalise, which is the definition of overfitting a ten-case set. Phrase lists remain hand-written and unmeasured against real repositories.
