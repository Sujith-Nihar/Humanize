- Evidence: Structural preservation implemented in packages/suggestions/src/index.ts. A candidate patch is applied in memory only, then the modified file is re-extracted and compared with the original: the parse must succeed, the node count must match, every node must keep its identity excluding position, exactly one node may differ, and that node must now contain precisely the proposed text. Anything else is rejected as STRUCTURE_CHANGED, TEXT_NOT_APPLIED or REPARSE_FAILED, and the finding falls back to a comment. This is what catches a replacement that is syntactically valid yet still wrong: a test proves prose opening a JSX expression or an HTML element is rejected, and that an attribute injection attempt is entity-encoded into literal text rather than becoming a new attribute.
