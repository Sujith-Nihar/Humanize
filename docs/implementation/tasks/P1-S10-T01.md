## Completion evidence

- Last updated: 2026-09-18T17:14:30.789792+00:00.
- Implementation revision: current working tree; no commit claimed.
- Evidence: Vue single-file-component extraction implemented with the official @vue/compiler-sfc parser. Static template text and visible or accessibility attributes are extracted; script, style, nested template, pre and code blocks are excluded, as are machine attributes. Offsets come from the compiler and are relative to the ORIGINAL file rather than the extracted template block, verified by a test asserting every node slice equals its own text. Interpolations and bound directives are never evaluated: a test proves {{ product.title }} and :alt="computedAlt" yield no prose, because resolving them would mean executing customer code (INV-001). Malformed SFCs return no nodes rather than failing the file. Measured by the extraction release gate at precision 100%, recall 100%, range accuracy 100%. Results: pnpm check 183 unit tests across 31 files; pnpm build passed; 40 integration tests passed.
