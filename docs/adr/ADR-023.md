# ADR-023 — Ambiguous external writes

Status: accepted in user-approved execution plan.
Concern: AC-03.

## Current design and problem

PostgreSQL cannot transact atomically with GitHub.

## Real-world consequence

Timeout after acceptance otherwise duplicates comments.

## Decision and implementation impact

Use stable markers, serialized publication attempts and reconciliation. Never blindly retry uncertain writes.

## Alternatives and verification

Retaining the ambiguous source interpretation was rejected because of the consequence above. Implement the smallest compatible change; test the relevant failure boundary before marking its mapped tasks complete.
