# ADR-031 — Ollama local-only inference

Status: accepted in user-approved execution plan.
Concern: AC-11.

## Current design and problem

A local Ollama endpoint can expose cloud features.

## Real-world consequence

Localhost is not sufficient evidence of private inference.

## Decision and implementation impact

Require local-only server configuration and local model capability checks; reject cloud-backed models.

## Alternatives and verification

Retaining the ambiguous source interpretation was rejected because of the consequence above. Implement the smallest compatible change; test the relevant failure boundary before marking its mapped tasks complete. See [roadmap](../implementation/README.md) and [requirements](../product/requirements.md).
